# Chain of Search Demo

A minimal demo using a summary search tool within the thinking tool.

## Installation

```bash
# create and activate a dedicated environment
python3 -m venv venv
source venv/bin/activate

# install our dependencies
pip install -r requirements.txt
```

## Usage

Run the following, or just `doc.sh`:

```bash
# activate the environment
source venv/bin/activate

# run the search tool
python search.py
```
